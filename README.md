# playerthree · 头戴式 FPS 辅助鼠标

> 陀螺仪头控 = 准星微位移的外设：头盯准星，手转身开枪，像「多加了一个鼠标」，互不干扰。
> 方案 v2.1 定稿（2026-08-28）｜ 目标：低价原型打开市场 → 高端竞技版

## 产品定义（两阶段路线）

| 阶段 | 形态 | 目的 |
|---|---|---|
| **原型（1 个月内）** | 独立头标 = 第二个 USB HID 鼠标 | 最快验证「头瞄手感」成立 |
| **V2 量产（验证后）** | 自有 2.4G 鼠标 + 头标 + **单接收器双通道**（一个 HID 输入） | 规避 VAC/EAC 反作弊顾虑 + 拉高客单价（先例：罗技 Unifying） |

## 系统架构

```
┌── 头戴方盒（≤50g，发带佩戴）──────────┐    ┌── USB 接收器 ──────────┐
│ Pro Micro (32U4 5V/16MHz)             │2.4G│ Pro Micro (32U4)      │
│  GY-521(MPU6050, I2C D2/D3)          │◄──►│  nRF24L01+             │──USB──▶ 电脑
│  nRF24L01+ (2Mbps, 关ACK, ≤1000Hz)   │    │  500-1000Hz→HID第二鼠标│  免驱动
│  锂电400mAh(≈7g)+TP4056升压 或 9V     │    │  USB 供电              │
│  开关键 + 灵敏度键(三挡)               │    └──────────────────────┘
└──────────────────────────────────────┘
```

- **延迟预算**：头端传感+融合 ~2ms + 空口 <1ms + 接收 ~1ms + HID 上报 1-2ms ≈ **5ms 级**（电竞可达）
- **回报率**：1000Hz 主（改 USB 描述符 polling=1ms）/ 500Hz 自动兜底

## 核心决策

- **角速度积分式控制**：`Δ位移 = 角速度×dt×灵敏度`，头停=准星停（倾角模式做不到 FPS 瞄准）
- **防抖防漂**：死区 + 带通滤波（去低频漂移+去高频微颤）+ 静止 1s 自动零偏校准 + 长按灵敏度键手动校准
- **双输入不打架**：Windows 多 HID 鼠标共享光标、增量叠加——头控与手鼠标天然独立
- **BOM ≈ ¥80**（完整见 docs/wiring.md），50g / 2h 续航指标宽松达标

## 快速开始（小白向）

1. Arduino IDE 打开 `firmware/head_unit/head_unit.ino`，不接硬件直接烧进 UNO（默认模拟模式）
2. 串口监视器 115200 看 dx/dy 规则平滑摆动 → M1 映射逻辑 OK；输入 `o`=开关键、`s`=灵敏度挡位、`h`=校准(预留)
3. 接线按 `docs/wiring.md`，把两个 .ino 顶部 `#define USE_SIM 1` 改 `0` 烧录 → W1
4. 手感调优只改头端文件顶部 5 个参数（DEADZONE/GAIN_A/GAIN_B/CLAMP/EMA）

## 风险速查

| 风险 | 对策 |
|---|---|
| VAC/EAC 对第二输入敏感 | V2 改单接收器套装形态；原型阶段实机首测 |
| 1000Hz 修改描述符失败 | 自动退 500Hz（仍达标率主流） |
| 2.4G 同频干扰 | 频道可调，接收器插主机后置 USB |
| 头部微颤 → 准星抖 | 死区+带通滤波+积分模型 |
| 颈部疲劳（假设：可能缓解长时间游戏不适） | W3/W4 问卷实测，不预设结论 |
