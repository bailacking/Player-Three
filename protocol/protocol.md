# playerthree 通信协议 v1.1

头戴端 → 接收端，每帧 8 字节，上报频率 **500-1000Hz**（1-2ms 一帧），小端序。

| 偏移 | 字段 | 说明 |
|---|---|---|
| 0 | 帧头 | 固定 `0xAA` |
| 1 | 按键 mask | bit0=开关键状态 ｜ bit1=灵敏度挡位 bit0 ｜ bit2=灵敏度挡位 bit1（挡位 0-2） |
| 2-3 | dx | `int16` 小端，X 轴位移（亚像素单位，接收端直通 HID） |
| 4-5 | dy | `int16` 小端，Y 轴位移 |
| 6 | 保留 | 恒 0（V2 预留滚轮/附加键） |
| 7 | sum8 | 偏移 0~6 求和 `& 0xFF` 校验 |

## 设计约定

- **发送端弃帧即弃，接收端校验失败即弃**——实时性 > 可靠性，下一帧 1-2ms 后到
- 位移 0 时接收端不发 `Mouse.move`，减 USB 流量
- 位移为增量而非绝对坐标：适配任意分辨率、免驱动（标准 HID 鼠标协议即增量）
- 灵敏度挡位由头端计算生效（增益乘法在头端完成），上传仅用于调试/上位机显示
- 开关键关闭时头端停止组包（省电+规避反作弊扫描期输入）
