# playerthree 头戴 FPS 辅助鼠标 · 工程方案 v2.1

> 状态：定稿（2026-08-28，产品形态经 4 轮访谈确认）｜ 一句话：陀螺仪头控=准星微位移，作为第二个 USB 鼠标与手鼠标并行，互不干扰

## 1. 产品定义

- **定位**：FPS 玩家的头控辅助外设——头动控制准星（微位移），手鼠标负责转身/开枪/滚轮
- **工作原理**：Windows 天然支持多 HID 鼠标共享光标，增量叠加 → 头控设备=普通 USB 鼠标外观，零驱动
- **两阶段路线**：
  - 原型（1 个月内）：独立头标 = 第二个 USB HID 鼠标，最快验证手感
  - V2 量产：自有 2.4G 鼠标 + 头标 + **单接收器双通道**（nRF24 6 管道天然支持），合并成一个 HID 输入 → 规避反作弊顾虑（先例：罗技 Unifying）

## 2. 验收标准

- [ ] 头端整机 ≤50g，续航 ≥2h（设计余量：实测预估 ≥8h）
- [ ] 端到端延迟 ≤5ms 级，回报率 1000Hz（失败自动退 500Hz）
- [ ] 接收器插入即视为 USB 鼠标，免驱动免软件
- [ ] 准星静止不漂（死区+自动校准+手动校准三层）
- [ ] W3/W4 实机自测 + 朋友试玩通过手感评审

## 5. 姿态与控制算法

- **角速度积分式**（FPS 核心）：每 1-2ms 读陀螺，`Δ位移 = 角速度 × dt × 灵敏度`；头停=增量零=准星停
- **死区**：|角度差| < 0.05° 视为静止，不输出
- **滤波**：死区 + EMA 低通（去高频微颤）+ **静止归零校准**（去低频零偏漂移）；已实现于 head_unit v2.2
- **校准三层**（已实现，2026-09-02）：静止 1s 自动零偏更新 ｜ 长按灵敏度键 ≥0.5s 手动校准 ｜ 上电 2s 稳定期（只读不输出）
- **灵敏度三挡**：增益 ×1 / ×1.5 / ×2.2（默认值，W3 实机按 CS2/Valorant 手感调）
- **开关键**：软开关——关闭时停止输出位移（也兼低功耗入口）

## 6. 无线与回报率

- nRF24L01+：2Mbps 数据率、关 auto-ack（丢包即弃，下一帧 1-2ms 后到）、**8 字节/帧**（v1.1 协议）
- 1000Hz 空口占用 ~4%，带宽充裕
- 接收端 32U4：**HID 原生 1ms 轮询 = 1000Hz 免改描述符**（官方 avr 核心 HID.cpp bInterval=0x01，2026-09-02 已核实）；固件默认 1000Hz，跟不上自动退 500Hz
- 频道可调（避开 WiFi/蓝牙耳机干扰），接收器建议插后置 USB

| 项 | 值 |
