# 接线手册 & BOM（小白向，照做版 v2.5）

> 真机模式（USE_SIM=0）依据。**电平红线：nRF24L01 与 MPU6050 只吃 3.3V，接板载 3V3，切勿接 5V！接错烧模块。**
> 阅读顺序：先看「零、准备」，再「一、头端」，再「二、接收端」，最后「三、电源开关」，全部做完看「四、验证」。

---

## 零、准备（5 分钟）

**你要认清的三个零件**（区分它们，别认错）：

| 零件 | 长什么样 | 作用 |
|---|---|---|
| **Pro Micro 板 ×2** | 长条形小板，一头是 Micro-USB/Type-C 口 | 两台「微型电脑」，一块戴头上、一块插电脑 |
| **GY-521 陀螺仪** | 小方块，面上印 `GY-521`，有一排针脚 | 感应头转的方向 |
| **nRF24L01+ 无线** | 小长条，一头有一块「铜花纹」天线 | 无线传数据（4 个，主备各 2） |

**你需要的手边工具**：杜邦线（公对公/公对母若干）、镊子、9V 电池（台面测试用）、电烙铁+热熔胶枪（加固用，不急）。

**接线总口诀**：`GND 全黑先接 → VCC 全 3V3 不碰 5V → 信号线按表一根根对`。

**每个 Pro Micro 的引脚长这样**（两块板同款，但接法不同！）：

```
USB 口在这头
[3V3] [RAW] [GND] [D2] [D3] [D4] [D5] [D6] [D7] [D8] [D9]
                [D10] [D14] [D15] [D16] [RX] [TX] ...
```

> ⚠️ 不同卖家丝印标记可能略有差异（有的写 `3.3V`，有的写 `3V3`；`RAW` 有的写 `VIN`）。**认位置：USB 口旁边第一个是 3V3/RAW/GND。**

## 一、头端接线（这块板将戴在头上）

**头端用：MPU6050 陀螺仪 + nRF24 无线 + 2 个按键 + Pro Micro 板。**

### ① 陀螺仪 GY-521 → Pro Micro（5 根线）

| 顺序 | GY-521 针脚 | → Pro Micro | 线色建议 | 易错点 |
|---|---|---|---|---|
| 1 | **GND** | → **GND** | 黑 | 先接地线 |
| 2 | **VCC** | → **3V3** | 红 | 🔴 **接 3V3 不是 5V！接 5V 必烧** |
| 3 | **SDA** | → **D2** | 黄 | I2C 数据线，接 D2 别接错 |
| 4 | **SCL** | → **D3** | 绿 | I2C 时钟线，接 D3 |
| 5 | **AD0** | → **GND** | 黑/灰 | 不接=地址变 0x69 会找不到设备 |

### ② 无线 nRF24L01+ → Pro Micro（7 根线）

| 顺序 | nRF24 针脚 | → Pro Micro | 线色建议 | 易错点 |
|---|---|---|---|---|
| 1 | **GND** | → **GND** | 黑 | |
| 2 | **VCC** | → **3V3** | 红 | 🔴 **同样只吃 3.3V** |
| 3 | **CE** | → **D9** | 白 | |
| 4 | **CSN** | → **D8** | 紫 | ⚠️ 头端是 D8！接收端才是 D10 |
| 5 | **SCK** | → **D15** | 橙 | SPI 时钟 |
| 6 | **MOSI** | → **D16** | 蓝 | |
| 7 | **MISO** | → **D14** | 棕 | |
| 8 | **IRQ** | 不接（悬空） | — | 千万别接到别处 |

### ③ 两个按键 → Pro Micro（各 2 根）

| 按键 | 一脚 | 另一脚 | 说明 |
|---|---|---|---|
| 开关键（大轻触按键） | → **D5** | → **GND** | 按下=头控暂停，松手=启用 |
| 灵敏度键（微动小开关） | → **D6** | → **GND** | 短按=挡位+1；长按≥0.5s=手动校准 |

> 微动小开关 3 个脚，只用「公共脚 + 一端」，另一端悬空，等效两脚按钮。跟三针拨动电源开关不一样，别混淆。

## 二、接收端接线（这块板插电脑 USB）

**接收端用：nRF24 无线 + Pro Micro 板 + 电脑 USB 供电。**

| 顺序 | nRF24 针脚 | → Pro Micro | 易错点 |
|---|---|---|---|
| 1 | **GND** | → **GND** | |
| 2 | **VCC** | → **3V3** | 🔴 3V3 |
| 3 | **CE** | → **D9** | |
| 4 | **CSN** | → **D10** | 🔴 **接收端是 D10！头端是 D8！反了不通** |
| 5 | **SCK** | → **D15** | |
| 6 | **MOSI** | → **D16** | |
| 7 | **MISO** | → **D14** | |
| 8 | **IRQ** | 不接 | |

**接收端不用电池**：USB 一插就供电，整块板=「无线鼠标接收器」。

## 三、电源开关（三针拨动小开关）

**作用**：真正切断头戴端电池电源，不用时彻底断电省电（锂电池放着也会慢慢漏光）。

三针开关 = 单刀双掷（SPDT），三个脚：**中间脚是「公共」，两边一脚是「通」一脚是「断」档**。

```
电池(+) ──┬── 开关中间脚 ──┬── TP4056/升压板 输入+ ── 升压板5V输出 ── Pro Micro RAW
            ↕ 另一边(断电档,悬空不接)
电池(-) ──────────────────────────────────────────────── GND
```

接法步骤：
1. 电池正极线接到开关**中间脚**（分不清就用万用表/电池扣试：拨一个方向万用表响=通电档）
2. 开关**一边脚**接到 TP4056 升压板 `B+/IN+`（输入正极）
3. 另一脚**悬空**（这就是断电档）
4. 升压板 `OUT+` → Pro Micro **RAW**；升压板 GND → 电池负 + Pro Micro **GND**
5. 拨到通电档：量 Pro Micro RAW 应有 ~5V；拨到断电档：0V

> 不想焊：先用杜邦线/电池扣夹住临时测试，确认拨动方向对了再上电烙铁。

## 四、上电验证（接完线照此顺序查）

**搞错顺序会烧件，按 1→2→3 来：**

### 1. 静态检查（通电前，2 分钟）
- [ ] 头端：3 根红线的去向——**3V3、3V3、3V3**（不是 5V）
- [ ] 头端 CSN=D8；接收端 CSN=D10（两根别拿反）
- [ ] 所有 GND 都接了（陀螺仪/无线/电池）
- [ ] nRF24 IRQ 都悬空没乱接

### 2. 接收端单独通电（USB 插电脑）
- [ ] 板子亮灯
- [ ] 电脑设备管理器 →「鼠标和其他指针设备」出现新鼠标（也许带黄色感叹号，可忽略）
- [ ] 如果之前烧的是 SIM 版，串口应显示 `[SIM] receiver 串口打桩模式`（真机版不显示，属正常）

### 3. 头端通电（9V 电池或锂电-升压-RAW）
- [ ] 板上灯亮
- [ ] **不晃时**：接收端鼠标纹丝不动
- [ ] **缓慢晃头**：光标跟随移动（方向反了改 head_unit.ino 里 mapAngle 返回取负）
- [ ] 按开关键（D5 接地）：光标立即停；松手恢复
- [ ] 短按灵敏度键：挡位循环；长按 ≥0.5s：串口出现 `[KEY] 手动校准完成`

## 烧录注意事项

1. **两块板都是 Pro Micro**：USB 直插烧录，无需下载器；板卡选「Arduino Micro / Leonardo（32U4）」
2. 接收端代码只能在 32U4 板编译；UNO 报 `Mouse was not declared` 属正常
3. 真机模式库**已装**：`RF24@1.6.2`、`MPU6050@1.4.5`（2026-09-02 arduino-cli 安装；重装系统后需重装：库管理器搜索安装）
4. MPU6050 出厂偏移：到手跑官方 `IMU_Zero` 示例，把 `head_unit.ino` 三个 `setX/Y/ZGyroOffset` 占位值换实测
5. 回报率：**32U4 HID 原生 1ms = 1000Hz**（官方 avr 核心 HID.cpp `bInterval=0x01`），无需改描述符；固件默认 1000Hz，跟不上自动退 500Hz
6. nRF24 3.3V 走线短；接收器天线朝上，插后置 USB
