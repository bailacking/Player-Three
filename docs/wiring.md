## 头端接线（Pro Micro — 与接收端同款板）

> 注意：32U4 的 I2C 在 D2(SDA)/D3(SCL)，**按键避开这两个脚**，用 D5/D6。

| 模块 | 引脚 | 接 Pro Micro | 备注 |
|---|---|---|---|
| MPU6050 | VCC → 板载 3.3V；GND → GND | | |
| | SDA → D2（丝印 SDA）；SCL → D3（丝印 SCL） | I2C | |
| | AD0 → GND | 地址 0x68 | |
| nRF24L01 | VCC → 板载 3.3V；GND → GND | | |
| | CE → D9；CSN → D8 | | |
| | SCK → D15；MOSI → D16；MISO → D14 | 32U4 SPI | |
| 开关键 | 一脚 → D5，另一脚 → GND | INPUT_PULLUP；按下=头控暂停，松手=启用 |
| 灵敏度键（微动小开关） | 一脚 → D6，另一脚 → GND | INPUT_PULLUP；**短按=挡位+1，长按≥0.5s=手动校准** |

**电源开关（三针拨动小开关，大帅购）**：串在电池正极通路上，拨到一边=供电，另一边=彻底断电。

```
锂电(+) ──┬── 开关 中间针 ──┬── TP4056/升压板 输入+ ── 升压 5V ── Pro Micro RAW
            ↕ 另一边针(断电档，悬空不接)
锂电(-) ──────────────────────────────── GND
```

> 三针拨动开关 = 单刀双掷(SPDT)：**中间针接锂电正极，选一边接升压板输入+，另一边悬空**。拨向接的那边=通电，拨向悬空边=断电。该开关做硬电源开关（彻底断电省电）——软开关键(D5)仍保留，可游戏中临时暂停头控，两者不冲突。

**供电（两路径）**：
- 台面验证（W1/W2）：9V 电池 → Pro Micro `RAW` 脚（元件清单现有件，**不用买**）
- 上头（W3 起）：锂电 → **电源开关** → TP4056 升压 5V → `RAW` 脚

## 烧录注意事项

1. **两块板都是 Pro Micro**：USB 直插烧录，无需下载器；板卡选「Arduino Micro / Leonardo（32U4）」
2. 接收端代码只能在 32U4 板编译；UNO 报 `Mouse was not declared` 属正常
3. 真机模式库**已装**：`RF24@1.6.2`、`MPU6050@1.4.5`（2026-09-02 arduino-cli 安装，位于 Arduino 库管理器 user 层；重装系统后需重装：库管理器搜索安装即可）
4. MPU6050 出厂偏移：到手跑官方 `IMU_Zero` 示例，把 `head_unit.ino` 三个 `setX/Y/ZGyroOffset` 占位值换实测
5. 回报率 1000Hz：**32U4 HID 原生 1ms 轮询**（官方 avr 核心 HID.cpp `bInterval=0x01`），无需改描述符；固件默认 1000Hz，实测跟不上自动退 500Hz
6. nRF24 3.3V 走线短；接收器天线朝上，插后置 USB
