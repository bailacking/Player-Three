# 接线手册 & BOM（小白向，照做版 v2.6）

> 真机模式（USE_SIM=0）依据。**电平红线：nRF24L01 与 MPU6050 只吃 3.3V，接板载 `VCC/3V3`，切勿接 5V！接错烧模块。**
> 本文按你手上的实际硬件写：**Pro Micro 左右两排共 24 针、GY-521 一排 8 针、nRF24L01+ 一排 8 针**。

---

## 零、认清你的三个零件（5 分钟）

### ① Pro Micro 板 ×2（左右各 12 针，共 24 针）

```
              ┌── USB 口（Micro-USB / Type-C）──┐
              左边一排（引脚1→12 从上到下）          右边一排
  ┌───────────────┐              ┌───────────────┐
  │ 1  TX   (D1)  │←── 串口发送    │ 13 RAW        │←── 外接电源输入(9V电池/升压5V)
  │ 2  RX   (D0)  │←── 串口接收    │ 14 GND        │←── 地
  │ 3  GND         │               │ 15 RST        │←── 复位
  │ 4  GND         │               │ 16 VCC 3V3     │←── 🔴 3.3V 输出(给陀螺仪/无线供电)
  │ 5  SDA  (D2)   │←── I2C 数据   │ 17 A3 (D21)    │
  │ 6  SCL  (D3)   │←── I2C 时钟   │ 18 A2 (D20)    │
  │ 7  A6   (D4)   │               │ 19 A1 (D19)    │
  │ 8  D5          │←── 开关键     │ 20 A0 (D18)    │
  │ 9  A7   (D6)   │←── 灵敏度键   │ 21 SCLK (D15)  │←── SPI 时钟
  │ 10 D7          │               │ 22 MISO (D14)  │←── SPI 数据出
  │ 11 A8   (D8)   │←── nRF24 CSN  │ 23 MOSI (D16)  │←── SPI 数据入
  │ 12 A9   (D9)   │←── nRF24 CE   │ 24 D10         │←── 接收端 nRF24 CSN
  └───────────────┘              └───────────────┘
```
> ⚠️ **认丝印不认位置**：不同卖家板面字母略有差异（如 `VCC` 可能标 `3V3`、`SDA/SCL` 可能标 `D2/D3`）。**以你板子上的印刷字母为准**，这张图用来帮你认「字母在哪一排、什么位置」。
> ⚠️ 个别 USB-C 版 clone 有 SCK/MISO 交换的翻车案例，接完必查下文「四、验证」。

### ② GY-521 陀螺仪（1 排 8 针）

```
  ┌─────────────────────────────────────────────┐
  │ GY-521                    [芯片正中间]          │
  └─┬──┬──┬──┬──┬──┬──┬──┬──┘
    1  2  3  4  5  6  7  8
```
板上 8 个针脚**从左到右**通常标字母（**以你板丝印为准**）：

| 针位 | 丝印 | 接往 Pro Micro | 作用 |
|---|---|---|---|
| 1 | **VCC** | → **VCC/3V3(16号)** | 🔴 供电，3.3V |
| 2 | **GND** | → **GND(3/4/14号)** | 地 |
| 3 | **SCL** | → **SCL/D3(6号)** | I2C 时钟 |
| 4 | **SDA** | → **SDA/D2(5号)** | I2C 数据 |
| 5 | XDA | 不接 | 接外部传感器才用 |
| 6 | XCL | 不接 | 同上 |
| 7 | **AD0** | → **GND** | 🔴 必须接 GND（固定设备地址 0x68） |
| 8 | INT | 不接 | 中断脚，本项目不用 |

### ③ nRF24L01+ 无线模块（1 排 8 针）

```
  ┌───────────────────────[天线铜纹]─┐
  └─┬──┬──┬──┬──┬──┬──┬──┬──┘
    1  2  3  4  5  6  7  8
```
板上 8 个针脚**从左到右**（**以你板丝印为准**）：

| 针位 | 丝印 | 接往 Pro Micro | 作用 |
|---|---|---|---|
| 1 | **GND** | → **GND** | 地 |
| 2 | **VCC** | → **VCC/3V3(16号)** | 🔴 供电，3.3V |
| 3 | **CE** | → **D9(12号)** 头端 / **D9(12号)** 接收端 | 使能 |
| 4 | **CSN** | → **D8(11号)** 头端 / **D10(24号)** 接收端 | 🔴 两块板不同！见各节 |
| 5 | **SCK** | → **SCLK/D15(21号)** | SPI 时钟 |
| 6 | **MOSI** | → **MOSI/D16(23号)** | 数据入 |
| 7 | **MISO** | → **MISO/D14(22号)** | 数据出 |
| 8 | **IRQ** | 不接 | 悬空 |

> ⚠️ 不同商家 GY-521/nRF24 的**针脚排序可能不同**（有的 VCC 在右），**一定按丝印字母认**，别按「第几个」接。

## 一、头端接线（这块板将戴在头上）

> 头端 Pro Micro 用：**陀螺仪(GY-521) + 无线(nRF24) + 2 按键**。把一块板编号为「头端板」。

### ① 陀螺仪 GY-521 → 头端板（7 针）

| 顺序 | GY-521 丝印 | 接到头端板哪个针（丝印） | 报线色 |
|---|---|---|---|
| 1 | **GND** | → **GND**(左边第3/4 或右边第14) | 黑 |
| 2 | **VCC** | → **VCC / 3V3**(右边第16) | 🟥 红 |
| 3 | **SDA** | → **SDA / D2**(左边第5) | 黄 |
| 4 | **SCL** | → **SCL / D3**(左边第6) | 绿 |
| 5 | **AD0** | → **GND** | 黑 |
| 6 | XDA | 悬空不接 | — |
| 7 | XCL | 悬空不接 | — |
| 8 | INT | 悬空不接 | — |

### ② 无线 nRF24 → 头端板（6 针，IRQ 不接）

| 顺序 | nRF24 丝印 | 接到头端板哪个针（丝印） | 报线色 |
|---|---|---|---|
| 1 | **GND** | → **GND** | 黑 |
| 2 | **VCC** | → **VCC / 3V3**(右边第16) | 🟥 红 |
| 3 | **CE** | → **D9**(左边第12，丝印 A9/D9) | 白 |
| 4 | **CSN** | → **D8**(左边第11，丝印 A8/D8) | 紫 |
| 5 | **SCK** | → **SCLK / D15**(右边第21) | 橙 |
| 6 | **MOSI** | → **MOSI / D16**(右边第23) | 蓝 |
| 7 | **MISO** | → **MISO / D14**(右边第22) | 棕 |
| 8 | **IRQ** | 悬空 | — |

### ③ 两个按键（各 2 针）

| 按键 | 一脚 | 另一脚 | 说明 |
|---|---|---|---|
| 开关键（大轻触按键） | → **D5**(左边第8) | → **GND** | 按下=头控暂停，松手=启用 |
| 灵敏度键（微动开关） | → **D6**(左边第9，丝印 A7/D6) | → **GND** | 短按=挡位；长按≥0.5s=校准 |

> 微动开关一般 3 个脚，用「中间公共脚 + 一端」，另一端悬空即可。

## 二、接收端接线（这块板插电脑 USB）

> 接收端 Pro Micro 只用：**无线(nRF24)**。把另一块板编号为「接收端板」——**和头端板 nRF24 的 CSN 接法不同**。

| 顺序 | nRF24 丝印 | 接到接收端板哪个针（丝印） | 报线色 |
|---|---|---|---|
| 1 | **GND** | → **GND** | 黑 |
| 2 | **VCC** | → **VCC / 3V3**(右边第16) | 🟥 红 |
| 3 | **CE** | → **D9**(左边第12，丝印 A9/D9) | 白 |
| 4 | **CSN** | → **D10**(右边第24) | 🔴 紫（**接收端是 D10！头端是 D8！**） |
| 5 | **SCK** | → **SCLK / D15**(右边第21) | 橙 |
| 6 | **MOSI** | → **MOSI / D16**(右边第23) | 蓝 |
| 7 | **MISO** | → **MISO / D14**(右边第22) | 棕 |
| 8 | **IRQ** | 悬空 | — |

**接收端不用电池**：USB 一插就供电，这块板=「无线鼠标接收器」。

## 三、电源开关（三针拨动小开关）

**作用**：切断头戴端电池电源，不用时彻底断电（锂电池放着也会慢慢漏光）。

三针开关 = 单刀双掷(SPDT)，**中间脚=公共**：

```
电池(+红) ──┬── 开关中间脚 ──┬── TP4056/升压板 输入+ ── 升压板 OUT+ ── Pro Micro RAW(13号)
              ↕ 另一边(断电档,悬空)
电池(-黑) ───────────────────────────────────────── GND ──────────── Pro Micro GND
```

1. 电池**正极**线 → 开关**中间脚**
2. 开关**任一边脚** → TP4056 升压板输入正极
3. 升压板输出 5V → Pro Micro **RAW**(右边第13);升压板 GND → 电池负 + Pro Micro **GND**
4. 拨到通电档量 RAW≈5V；断电档=0V

## 四、上电验证（接完按 1→2→3 查，顺序错会烧件）

### 1. 静态检查（通电前，逐项画勾）
- [ ] 头端 **3 根红线**全部接在 `VCC/3V3`（陀螺仪、无线、若有时钟），**没有碰到 5V**
- [ ] 头端 nRF24 CSN=**D8**；接收端 nRF24 CSN=**D10**（两块板别对调）
- [ ] 所有 GND 接线（陀螺仪/无线/电池）齐全
- [ ] 两块板 nRF24 的 IRQ 都悬空，没乱接
- [ ] GY-521 的 AD0 接了 GND

### 2. 接收端单独通电（插电脑 USB）
- [ ] 板子灯亮
- [ ] 设备管理器 →「鼠标和其他指针设备」出现新鼠标
- [ ] SIM 版会显示 `[SIM] receiver 串口打桩模式`；真机版不显示属正常

### 3. 头端通电（9V 电池或锂电-升压→RAW）
- [ ] 板上灯亮
- [ ] 不晃头 → 接收端鼠标不动
- [ ] 缓慢晃头 → 光标跟随（方向反了改 `head_unit.ino` 的 `mapAngle` 返回取负）
- [ ] 按开关键(D5)：立即停；松手恢复
- [ ] 短按灵敏度键：挡位循环；长按≥0.5s：串口 `[KEY] 手动校准完成`

## 六、烧录注意事项

1. **两块板都选「Arduino Micro / Leonardo（32U4）」**；USB 直插烧录免下载器
2. 接收端代码只能在 32U4 板编译；UNO 报 `Mouse was not declared` 属正常
3. 真机模式库已装：`RF24@1.6.2`、`MPU6050@1.4.5`（2026-09-02 arduino-cli 装好）
4. MPU6050 出厂偏移：跑官方 `IMU_Zero` 示例，把 `head_unit.ino` 三个 `setX/Y/ZGyroOffset` 占位值换实测
