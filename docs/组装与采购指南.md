# playerthree · 组装与采购指南（v2.2）

> 面向：没有任何焊接工具的新手。目标：照着这份文档，自己在淘宝买对零件、插好线、跑通原型。
> 关键前提：**所有模块买「已焊好排针」的成品版，全程零焊接**。

## 一、采购规格判断表（看到选项怎么选）

### 1. Arduino Pro Micro ×2 —— 最容易选错的一件

| 商家选项 | 选择 | 原因 |
|---|---|---|
| 带排针 / 不带排针 | **带排针** | 不带=给你一包针自己焊，你没有烙铁 |
| 排针向上 / 排针向下 / 弯针 | **排针向上（直针）** | 指针朝上，杜邦线从上往下插最顺手；也兼容立插面包板 |
| 5V/16MHz / 3.3V/8MHz | **5V/16MHz** | 板载 5V 稳压，9V 电池可以直接喂 |
| Micro-USB / Type-C 口 | Type-C 优先（没有就 Micro） | Type-C 线手机随手有；Micro 需另买线 |
| 原装片 / 国产兼容片 | 均可 | 功能无差别 |
| 同店有「带排针已焊好」的字样 | 认准 | 到货即用 |

> **买 2 块**：1 块作头端主控、1 块作接收端。同型号好处：烧录方式一样、备件通用。
> **配套要买**：Type-C（或 Micro-USB）**数据线 1-2 根**（必须 4 芯数据线，不是充电线；烧录和调试都要用）。

## 二、头端接线（Pro Micro 板卡）

```
                        头戴端 Pro Micro（ATmega32U4）
┌─────────────────────────────────────────────────┐
│              USB 口（靠边）                        │
│  [3V3] [RAW(VIN 电源入)] [GND]                    │
│  [D2←SDA] [D3←SCL]  ←-- I2C 连陀螺仪             │
│  [D9←CE] [D8←CSN]                                │
│  [D15←SCK] [D16←MOSI] [D14←MISO]  ←-- SPI 连无线 │
│  [D5←开关键] [D6←灵敏度键] [GND←按键另一端]         │
└─────────────────────────────────────────────────┘
```

| 陀螺仪 GY-521 引脚 | 接 Pro Micro | 说明 |
|---|---|---|
| VCC | → **3V3** | 红线（5V 会烧！） |
| GND | → **GND** | 黑线 |
| SDA | → **D2** | 黄/绿线 |
| SCL | → **D3** | 另一色 |
| AD0 | → **GND** | 固定 I2C 地址 0x68，必须接 |

| 无线 nRF24L01+ 引脚 | 接 Pro Micro | 说明 |
|---|---|---|
| VCC | → **3V3** | 红线（只吃 3.3V） |
| GND | → **GND** | 黑线 |
| CE | → **D9** | |
| CSN | → **D8** | |
| SCK | → **D15** | |
| MOSI | → **D16** | |
| MISO | → **D14** | |
| IRQ | → 不接 | 悬空 |

| 按键 | 接法 |
|---|---|
| 开关键（大轻触按键） | 一脚 → D5，另一脚 → GND |
| 灵敏度键 | 一脚 → D6，另一脚 → GND |

**供电（二选一）**：
- **台面验证**：9V 电池 + 电池扣 → 红线上 `RAW`，黑线 `GND`
- **上头（装盒后）**：锂电（JST 头）→ TP4056 升压板 → 升压板 5V 输出 → `RAW`，GND→`GND`；**拨动开关串在电池与充电板之间**（或充电板输出与 RAW 之间）

> 接线口诀：**所有 GND 先接；VCC 全部 3V3 不碰 5V；电源红对正黑对负防反接。**

## 三、接收端接线（Pro Micro 板卡）

```
┌────────────────────────────────────┐
│ 接收端 Pro Micro（插电脑 USB 口）     │
│  [3V3] [GND]                        │
│  [9←CE] [10←CSN]                    │
│  [15←SCK] [16←MOSI] [14←MISO]       │
└────────────────────────────────────┘
```

| nRF24 引脚 | 接 Pro Micro | 说明 |
|---|---|---|
| VCC | → 3V3 | |
| GND | → GND | |
| CE | → D9 | |
| CSN | → **D10** | 接收端 CSN 用 D10（32U4 的 SS） |
| SCK/MOSI/MISO | → D15/D16/D14 | |
| IRQ | 不接 | |

**供电**：插电脑 USB 即供电（实测 <50mA，USB 口无压力）。接收端整块板就是「无线鼠标接收器」。

## 四、头戴端盒内布局（装盒阶段）

```
顶视：发带佩戴时，盒子在孩子额/头顶正中，印刷面朝上
┌──────────────────────────────┐
│  [nRF24]（天线朝前/朝上，远离金属）│
│      ┌────────────┐           │
│      │ GY-521     │ ← 紧贴盒盖，双面胶粘牢，绝不能晃 │
│      │ (印刷面朝上)│           │
│      └────────────┘           │
│  [Pro Micro] 平放              │
│  ┌────────────────┐           │
│  │  锂电(软包)平铺   │ ← 最底层，最重放最下 │
│  └────────────────┘           │
└──────────────────────────────┘
```

要点：
- **盒子尺寸建议 50×35×15mm**（三块板+电池平铺放得下）；先拿扎带裸固定也可以，盒子不急
- **GY-521 必须贴牢**（双面胶+扎带都行）：传感器晃动=准星抖，这是头控体验的第一杀手
- 电池在底层（最重），靠人体侧；Pro Micro 中间；nRF24 放在天线不被头和手遮挡的位置
- 盒子上打两个孔穿发带，或魔术贴
- 上头前先台面把链路全部调通（见第五节），别直接戴

## 五、组装与调试顺序（照做，别跳步）

| 步 | 动作 | 验证标准 |
|---|---|---|
| 0 | （现在就能做）UNO 烧 `head_unit.ino`（SIM 模式）看串口 | dx/dy 规则平滑摆动 |
| 1 | 两块 Pro Micro 各自 USB 插电脑，Arduino IDE 选板「**Arduino Leonardo**」（32U4），烧 SIM 版 | 两板串口都能输出 |
| 2 | 只接陀螺仪（I2C 4 根线）→ 烧 I2C Scanner 示例 | 扫描到 `0x68` |
| 3 | `head_unit.ino` 改 `USE_SIM 0` 烧录 → 串口晃板子 | 角度随晃动变化、静止归零 |
| 4 | 接 nRF24（头端+接收端）→ 接收端烧 `receiver.ino`（`USE_SIM 0`） | 接收端串口打印 mask/位移；插电脑出现「鼠标」设备 |
| 5 | 上位测试：头端 9V 供电，戴发带，Windows 桌面轻晃头 | 光标跟随，开关键/S 键生效 |
| 6 | 换锂电+升压+开关 | 续航测试 ≥2h |
| 7 | 装盒、贴牢、调整灵敏度三挡 | 实际打一局 CS2/Valorant 顺手 |

> 第 3 步前：跑官方 `IMU_Zero` 示例，把实测偏移写进 `head_unit.ino` 三行 `setX/Y/ZGyroOffset`。

## 六、你没想到的问题清单（Q&A）

1. **排针向上/向下/弯针**：选「直针向上」——杜邦线从上往下插最舒服，也兼容立插面包板。弯针是给贴板面走线用的，小白不用碰。
2. **为什么还要买「公对公」杜邦线**：面包板孔↔面包板孔必须公对公；你的公对母只够「模块排针↔面包板」。台面三分之一连接是公对公。
3. **Pro Micro 插电脑没反应/烧不进**：①Win10+ 免驱，连不上先换根 4 芯数据线 ②IDE 选板必须是 32U4 系列（Leonardo/Micro/SparkFun Pro Micro）③上传瞬间可能要求「点完上传立刻插上」（部分款无自动复位，商家页面会写）
4. **头戴端怎么彻底关机**：买拨动开关串电池正极（清单第 6 款）；锂电池+充电板通路一直有 mA 级耗电，2-3 天漏光，硬开关是必须品
5. **电池/5V 会烧吗**：锂电→升压→RAW 路径安全；**别把任何 5V 接到 3V3 或 GY-521/nRF24 的 VCC**；电源先焊对再上电，黑线（GND）先接
6. **接收端插上没看到「鼠标」**：HID 设备在系统「设备管理器→鼠标」里看，托盘不显示是正常的
7. **两块板都要 USB 线吗**：调试轮流插一根即可（插一块烧一块）；当然两根更省事
8. **2.4G 干扰**：WiFi/无线耳机同在 2.4GHz；通道在 `head_unit.ino` 的 `radio.setChannel(76)` 可改（0-125），干扰就换
9. **nRF24 天线别贴金属/别被头挡住**：盒内天线朝外；接收端天线朝上、插主机后置 USB
10. **陀螺仪为什么必须贴牢**：传感器每抖一下，准星就抖一片；贴牢是第一手感要素
11. **锂电别过放**：带保护板会断电保护，但别等到保护（电压低于 3.0V 伤电池）；电量低就充（TP4056 红灯充、转蓝充满）
12. **备用板什么时候用**：接线接错、模块烧坏时换（这也是为什么多买一块 GY-521 和一对 nRF24）
13. **900/500Hz 回报率**：默认代码 500Hz（回来了就好用了），1000Hz 是 V2 优化项，别为它卡采购
14. **FPS 手感调节入口**：`head_unit.ino` 顶部 `DEADZONE_ANG / GAIN_A / GAIN_B / CLAMP_PX / EMA_ALPHA` 五个参数；三挡灵敏度键是运行时切换
15. **Windows「提高指针精确度」**：FPS 玩家建议关闭，头控手感更跟手
